# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
If you discover a security vulnerability within AutoMaintainer, please send an e-mail to our security team. All security vulnerabilities will be promptly addressed.
